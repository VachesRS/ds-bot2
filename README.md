# 🛡️ Discord Бот с Автомодерацией

Современный модульный Discord-бот на **Python 3.12** с библиотекой **discord.py 2.x**, слэш-командами (`/`), базой данных SQLite для учета нарушений и автоматической эскалацией наказаний.

---

## 🚀 Основные возможности

### 🤖 Автомодерация (`cogs/automod.py`):
1. **Анти-спам / Флуд**:
   - Отслеживает частоту сообщений (более 5 сообщений за 4 секунды).
   - Удаляет флуд и выдает тайм-аут (мут) на 5 минут.
2. **Анти-инвайт**:
   - Блокирует сторонние ссылки-приглашения на другие Discord-серверы (`discord.gg/...`, `discord.com/invite/...`).
3. **Анти-капс**:
   - Удаляет сообщения, состоящие более чем на 70% из заглавных букв (при длине от 10 символов).
4. **Анти-массменшн**:
   - Пресекает спам упоминаниями (от 5 участников) и несанкционированный пинг `@everyone` / `@here` (тайм-аут на 15 минут).
5. **Фильтр NSFW (18+ картинок, файлов и GIF)**:
   - **Локальная нейросеть (ResNet-50 OpenNSFW)**: Анализирует саму анимацию GIF покадрово (извлекает ключевые кадры и оценивает их визуальное содержание на наличие взрослого контента), а также проверяет статичные картинки (.png, .jpg, .webp).
   - **Анализ тегов и ссылок**: Сканирует GIF-ссылки, слаги и эмбеды из **Klipy**, **Tenor** и **Giphy**.
   - **Умное разделение каналов**: В каналах с возрастным ограничением Discord (NSFW) контент разрешен, в обычных каналах — блокируется.
6. **Логирование**:
   - Отправка подробных Embed-логов в специальный канал (участник, канал, текст сообщения, причина, принятая мера).

### 🔨 Слэш-команды (`cogs/moderation.py`):
- `/timeout @user [минуты] [причина]` — отправить участника в тайм-аут (мут).
- `/untimeout @user [причина]` — досрочно снять тайм-аут.
- `/kick @user [причина]` — выгнать нарушителя с сервера.
- `/ban @user [причина] [дни_удаления]` — забанить нарушителя.
- `/clear [кол-во]` — быстрая очистка сообщений в канале (от 1 до 100).
- `/setlogs #канал` — назначить текстовый канал для логов автомодерации.
- `/automod_toggle [модуль] [True/False]` — включить или отключить конкретный фильтр (включая NSFW и иммунитет админов).
- `/automod_status` — посмотреть текущий статус всех модулей и канала логов.

## 🛠️ Пошаговая настройка и запуск

### Шаг 1. Создание бота в Discord Developer Portal
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **New Application**, введите имя бота и нажмите **Create**.
3. Перейдите во вкладку **Bot** в левом меню:
   - Нажмите **Reset Token** (или **Copy Token**), чтобы скопировать токен бота.
   - **ОБЯЗАТЕЛЬНО**: Прокрутите страницу вниз до блока **Privileged Gateway Intents** и включите:
     - ✅ **PRESENCE INTENT**
     - ✅ **SERVER MEMBERS INTENT**
     - ✅ **MESSAGE CONTENT INTENT** *(Без этого автомодерация не сможет читать текст сообщений!)*
   - Нажмите **Save Changes**.

### Шаг 2. Приглашение бота на ваш сервер
1. В меню слева выберите **OAuth2** -> **URL Generator**.
2. В блоке **Scopes** отметьте:
   - ✅ `bot`
   - ✅ `applications.commands`
3. В появившемся ниже блоке **Bot Permissions** отметьте:
   - ✅ **Administrator** (или вручную: Manage Roles, Manage Channels, Kick Members, Ban Members, Moderate Members, View Channels, Send Messages, Manage Messages, Embed Links, Read Message History).
4. Скопируйте ссылку внизу страницы, откройте в браузере и добавьте бота на ваш сервер.
5. **Важно на сервере**: В настройках ролей вашего сервера поставьте роль бота **выше** ролей обычных участников, иначе бот не сможет выдавать им мут или кикать!

### Шаг 3. Настройка токена в проекте
1. Откройте файл `.env` в этой папке.
2. Вставьте ваш токен:
   ```env
   DISCORD_TOKEN=ваш_скопированный_токен
   LOG_CHANNEL_ID=0
   ```
3. Сохраните файл.

### Шаг 4. Локальный запуск на ПК
Просто дважды кликните по файлу `run.bat` или выполните в консоли:
```bash
python main.py
```

## 🌐 Как запустить бота 24/7 без включенного ПК (через GitHub)

> [!CAUTION]
> Никогда не добавляйте ваш файл `.env` на публичный GitHub! 
> Файл `.gitignore` уже настроен и защищает ваши секретные данные.

### Вариант 1: Бесплатный хостинг Koyeb или Render
1. Создайте бесплатный репозиторий на [GitHub](https://github.com/new) (например, `discord-automod-bot`).
2. Загрузите файлы этого проекта на GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/discord-automod-bot.git
   git push -u origin main
   ```
3. Зарегистрируйтесь на **[Koyeb.com](https://www.koyeb.com)** или **[Render.com](https://render.com)**.
4. Нажмите **Create Service** / **New Background Worker** и выберите ваш GitHub-репозиторий.
5. В настройках **Environment Variables** (переменные окружения) добавьте:
   - Ключ: `DISCORD_TOKEN`
   - Значение: *ваш токен бота*
6. Нажмите **Deploy**. Сервер соберет бота и запустит его в облаке 24/7!

### Вариант 2: Специализированный хостинг Discloud
1. Зарегистрируйтесь на [Discloud](https://discloud.com/).
2. В проект уже включен файл `discloud.config`.
3. Упакуйте файлы бота в `.zip` (включая ваш `.env` и `discloud.config`) и загрузите в панель Discloud.
4. Бот мгновенно запустится онлайн.
