# 🐾 Kobi — Многофункциональный Discord-бот

![Kobi Mascot](kobi_avatar.jpg)

Современный, мощный и модульный Discord-бот нового поколения в стиле **Carl-bot** и **JuniperBot**, написанный на **Python 3.12** и **discord.py 2.x**. Оснащен интерактивным веб-дашбордом, системой уровней, карточками приветствия, ролями по кнопкам, временными голосовыми каналами, розыгрышами, конструктором эмбедов и AI-автомодерацией.

---

## ✨ Основные модули и возможности

### 1. 📊 Уровни и опыт (XP) (`cogs/levels.py`):
- Начисление опыта за текстовые сообщения с защитой от спама (кулдаун 60 сек).
- **Стильные графические Rank-карточки (Pillow)**: аватарка пользователя, уровень, ранг на сервере, прогресс-бар XP и процент заполнения.
- Слэш-команды:
  - `/rank [пользователь]` — персональная графическая карточка опыта.
  - `/leaderboard` — таблица лидеров сервера по уровню и XP.
- Автоматическая синхронизация с веб-дашбордом.

### 2. 🎭 Интерактивные роли по кнопкам (`cogs/button_roles.py`):
- Выдача и снятие ролей в один клик через Discord UI Buttons (без реакций).
- Поддержка нескольких ролей в одном сообщении.
- Постоянные вьюхи (Persistent Views), работающие даже после перезапуска бота.
- Слэш-команды:
  - `/buttonrole setup` — создание стильного меню выбора ролей.
  - `/buttonrole autorole` — автоматическая выдача роли при входе новичка на сервер.

### 3. 👋 Приветствия и карточки участников (`cogs/welcome.py`):
- **Графические Welcome-карточки**: генерация красивой картинки при входе нового участника с его аватаром, именем и номером на сервере.
- Автоматическая отправка приветственного эмбеда в указанный канал.
- Слэш-команда:
  - `/welcome channel` — выбор канала для приветствий.

### 4. 🔊 Временные голосовые каналы («Создать канал») (`cogs/temp_voice.py`):
- Автоматическое создание персональных голосовых комнат при подключении к триггер-каналу.
- Автоматическое удаление пустой комнаты, когда все участники выходят.
- Слэш-команда:
  - `/tempvoice setup` — настройка хаба временных каналов.

### 5. 🎉 Розыгрыши и гивевеи (`cogs/giveaways.py`):
- Создание розыгрышей с интерактивной кнопкой «🎉 Участвовать» и счетчиком участников.
- Автоматический отсчет таймера и честный выбор победителя(ей).
- Слэш-команда:
  - `/giveaway start [длительность] [победителей] [приз]`.

### 6. 🎨 Визуальный конструктор Embed-сообщений (`cogs/embed_builder.py`):
- Создание красивых объявлений, правил и оформленных сообщений без ручного JSON.
- Удобное модальное окно Discord Modal: заголовок, описание, цвет, картинка, футер.
- Слэш-команда:
  - `/embed create`.

### 7. 🛡️ AI-Автомодерация и фильтры (`cogs/automod.py`):
- **Анти-спам / Флуд**: защита от быстрой отправки сообщений (мут на 5 мин).
- **Анти-инвайт**: блокировка сторонних ссылок-приглашений (`discord.gg/...`).
- **Анти-капс**: пресечение сообщений с >70% заглавных букв.
- **Анти-массменшн**: защита от спама тегами (`@everyone`, `@here`, массовые упоминания).
- **Фильтр NSFW (18+)**: локальная нейросеть ResNet-50 + проверка GIF/ссылок Tenor/Giphy.
- **Анти-токсичность**: фильтрация мата и оскорблений.
- **Подробное логирование**: Embed-логи всех нарушений в отдельный канал.

### 8. 🌐 Веб-панель управления (Web Dashboard) (`web/`):
- Вход через Discord OAuth2.
- Главная страница со статистикой: сервера, участники, аптайм, пинг, распределение нарушений.
- Панель управления настройками каждого сервера в реальном времени.
- Просмотр таблицы лидеров и логов прямо из браузера.

## 🛠️ Быстрый старт

### 1. Настройка в Discord Developer Portal
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications).
2. Выберите вашего бота или создайте нового (**Kobi**).
3. Во вкладке **General Information**:
   - Загрузите аватарку из файла `kobi_avatar.jpg` (или `avatar.png`).
4. Во вкладке **Bot**:
   - Скопируйте токен.
   - В блоке **Privileged Gateway Intents** обязательно включите:
     - ✅ **PRESENCE INTENT**
     - ✅ **SERVER MEMBERS INTENT**
     - ✅ **MESSAGE CONTENT INTENT**
5. Во вкладке **OAuth2** -> **URL Generator**:
   - Scopes: `bot`, `applications.commands`
   - Permissions: `Administrator`
   - Скопируйте ссылку и пригласите бота на сервер.
   - *Важно:* Переместите роль бота выше ролей обычных участников.

### 2. Конфигурация `.env`
Заполните файл `.env`:
```env
DISCORD_TOKEN=ваш_токен_бота
DISCORD_CLIENT_ID=id_клиента
DISCORD_CLIENT_SECRET=секрет_клиента_oauth2
REDIRECT_URI=http://localhost:5000/callback
SESSION_SECRET=секретный_ключ_для_сессий
WEB_PORT=5000
LOG_CHANNEL_ID=0
```

### 3. Локальный запуск
Запустите бота через `run.bat` или в консоли:
```bash
python main.py
```
Веб-дашборд откроется по адресу `http://localhost:5000`.
